接続設定

OpenAI 互換 API。末尾の /v1 は省略可能です（ルート URL の場合）。

API サーバーから見た接続先です。別端末のブラウザでも、サーバー上の Engine は 127.0.0.1 で指定できます。

詳細設定

キーはこのタブだけで保持し、保存しません。LAN 内 HTTP では送信は暗号化されません。

未対応のモデルでは「接続先の既定値」を選んでください。

句点の追加時間は話速と独立です。0.8で読点のポーズ指定を20%短縮。オフで従来の間に戻ります。

構文解析は係り受けと先読みの安定性を確認します。自然さを保証するものではありません。

オンでは返答中もマイク音声をVADへ送ります。話し始めると返答を中断します。ブラウザのエコー抑制を使いますが、スピーカー音でも誤作動する場合があるためヘッドホンを推奨します。

導入済みのモデルのみ選べます。変更しても下書きは送信しません。

音声会話の発話検出

音声会話はVAD＋Parakeetを使います。途中の文字は表示せず、認識した最終文をLLMへ送信して履歴に残します。通常の「マイク」は文字入力だけです。
